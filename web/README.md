# 值班台 Web 界面（D6 交付）

单页控制台，MVP 面板清单（对应 README 架构图的展示层）：

1. **实时告警流**：分级着色（normal / watch / alarm / critical）
2. **声学面板**：波形 + 频谱 + 告警特征高亮
3. **视觉面板**：最新抽帧 + 检测框叠加
4. **态势面板**：航线走廊 + 本船位置（NMEA 回放）+ 雷达 PPI 目标叠加
5. **日志与报告**：自动生成的轮机日志、巡检报告预览
6. **轨迹回放**：选择两次执行做 diff（Harness trajectory.jsonl）

技术选型候选：FastAPI（本地 only，127.0.0.1）+ 原生 HTML/JS；不引入构建链，保证 ARM64 上零依赖部署。
