# 十日谈 · Day 2（2026-09-21 晚）：大脑上线，然后被自己写的内存泄漏搞挂了

> 本文是"十日谈"第三篇。[前一篇：上真机](链接)。

## 上午：大脑上线

StepFun 的 key 到位后，我们把 step-3.7-flash（262K 上下文 + 视觉）接成编排大脑。模型阵容比预期好：step-5-preview 有 1M 上下文可做升级选项，step-tts-2 / step-asr 直接把语音链路也解决了——不用另找方案。

路由三连全过，包括最关键的负例：问"今天晚饭吃什么"，大脑必须返回 NONE（不触发任何 Skill），禁止硬凑。这个负例比正向用例更难写，也更重要——一个乱触发的值守系统比没有系统更危险。

## 晚上：我们把自己写的服务搞挂了

晚饭后出了今天最大的事故：**vLLM 容器把整台节点搞死了**，SSH 认证通过但会话建不起来，连 shell 都进不去。

根因是我们对 GB10 "统一内存"的理解不够深：121GB 是 CPU 和 GPU 共用的池子，vLLM 默认 `gpu-memory-utilization 0.9` 意味着吃掉全机内存的 90%——哪怕跑的只是个 4B 小模型。进程调度被饿死，三小时后 Linux OOM killer 自己把容器杀了，节点才恢复。

恢复后修了三件事，把参数固化进启动脚本：

1. `--gpu-memory-utilization 0.45`（4B 模型只需要约 50GB，别贪）
2. `FLASHINFER_DISABLE_VERSION_CHECK=1`（预置镜像里 flashinfer 版本不匹配，绕过）
3. `--enforce-eager`（跳过 CUDA graph 捕获，这条路径在 ARM64 上有问题）

重启后 `Application startup complete` 出现，**本地推理端点正式打通**。然后做了今天最有价值的验证：**双端点回归对照**——同一个路由用例集，分别打本地 Qwen3-4B 和 StepFun step-3.7-flash，**6/6 全部一致**（含负例）。这就是"换模型只改三个值 + 回归评测证明行为等价"的完整实证，也顺手把"平台适配性"的评分项做实了。

## 另一个发现：AE 在真实数据上倒挂

声学双轨的对照评测也出了第一批真实数据结果，有个意外：**自编码器的带符号重构误差在 pump 上 AUC 只有 0.260**——比随机还差。诊断后发现不是 bug：这个子集的异常是"信号变更弱"（异常段特征能量反而更低），AE 把异常重建得更好，误差符号就反了。

换成方向无关的偏离度分数后回到 0.797。这个发现比一个好看的数字更有价值：它证明"异常=重构误差更高"这个 DCASE 默认假设在真实数据上不总成立，而我们的启发式轨（z-score 天然方向无关）正好互补。两种口径在代码里同时报告，不藏结果。

## 三个教训

1. **GB10 统一内存 + vLLM：小模型也必须显式限容**。默认参数是给独立显存机器设计的。
2. **节点禁 reboot**，出问题只能等 OOM killer 自救或组委会从跳板机处理——资源参数要保守。
3. **负向用例的价值今天体现两次**：大脑的 NONE 路由、声纹的 unknown 判定，都是"不乱来"比"做对"更难写。
