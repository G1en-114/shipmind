# 船舶安全管理体系（SMS）应急程序摘要（合成）

> ⚠️ 本文档为演示用自拟文档，参照 ISM Code 与船公司 SMS 的通行结构编写；
> 不指向任何真实公司体系文件。

## 1. 机舱进水应急

1. 发现者立即报告值班轮机员与驾驶台
2. 启动舱底水系统排水，隔离进水源（关闭相关阀门/舱壁贯穿件）
3. 必要时启动应急消防泵保障冷却水
4. 评估稳性影响，报告船长
5. 记录：时间、部位、处置措施、参与人

## 2. 主机故障丧失动力

1. 报告驾驶台，显示失控信号
2. 尝试复位/重启；检查燃油、滑油、冷却、压缩空气系统
3. 按航线情况评估是否需要抛锚
4. 通知船东与公司机务

## 3. 轴承异响告警的标准响应

1. 确认告警设备与参数（机舱、声学证据）
2. 现场复核：温度、振动、泄漏、声音
3. 具备备用设备时切换运行，记录切换时间
4. 不具备备用条件时降负荷运行并加强监视（每 15 分钟记录一次）
5. 报轮机长决定后续检修安排

## 4. 火灾应急（机舱）

1. 报警、报告驾驶台、切断相应电源与燃油
2. 初期火灾用灭火器/固定灭火系统处置
3. 封舱灭火时确认人员全部撤离并清点
4. 船长决定是否请求外部援助

## 5. 人员落水

1. 驾驶台立即抛下救生圈，派人落水点瞭望
2. 操纵船舶返回（威廉姆森旋回或单旋回）
3. 机舱备车，准备救助艇
4. 报告 VTS 与附近船舶

## 6. 记录要求

所有应急行动须记录：发现时间、报警时间、处置步骤、完成时间、损失情况。
记录保存于航行日志与机舱日志，作为 PSC 检查与公司审核依据。
