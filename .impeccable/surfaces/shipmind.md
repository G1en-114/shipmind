# ShipMind 操作台

Mode: Operate。项目介绍和手册结果使用 Read 模式。

THESIS: 以告警和观测为入口，将本地分析变成可浏览的证据。

OWN-WORLD: 接近 Apple 产品界面的浅灰画布、白色分组面板、系统字体与单一蓝色操作色；绿色只表示正常连接，橙色和红色只表示需要关注。用留白、字号和细分隔线建立层级，不依赖装饰性背景。

STORY: 总览 → 检查态势/机舱 → 查手册 → 阅读报告和轨迹。项目介绍解释已实现能力、双端点和官方集成边界。

FIRST VIEWPORT: 固定左导航，紧凑的连接/刷新栏；360° PPI 是主视区，右侧为告警；下方声学与视觉证据按阅读顺序延展。数值使用等宽数字，中文使用系统无衬线。

FORM: 代码优先由用户明确选择。context 和 concept-seed 均因引擎未安装及缓存目录写入限制失败；本轮按主技能的降级条款，依据项目资料构建，无 seed key，不声称经过随机方向选择或效果图批准。操作台优先的用途待用户反馈，已用异步问题询问。

Signature interaction: 点击目标列表同步突出 PPI 中的目标；切换量程保留真实方位和距离，超量程目标明确提示。刷新时保持阅读位置，完成后更新时间。

Motion: 160ms 状态过渡，无装饰性雷达扫描；尊重 reduced-motion。

Verification: 桌面 1440px 与移动 390px 同批浏览器检查；再至多一轮修复确认。本地素材图来自分析接口，无新生成位图。
