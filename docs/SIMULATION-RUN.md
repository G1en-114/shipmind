# 本地动态仿真案例

当前 Web 值班台支持一条可重复的本地仿真值班流。它使用仓库内自产夹具，不冒充真实船舶遥测：

- `/api/spectrum` 从异常泵音频提取基线频谱，再叠加确定的时间相位与微小扰动；每次响应带 `frame`、`sampled_at` 和 `synthetic: true`。
- `/api/visual` 轮换 `evals/fixtures/gauges/train/` 中的合成表盘帧，并调用视觉巡检脚本保留读数、检测框和拒判结果。
- 前端首次刷新加载全部六路观测；自动刷新开启时，频谱和表盘每 3 秒轻量更新一次，告警、态势、轨迹和报告仍按手动刷新更新。

## 启动

```powershell
python -m uvicorn web.server:app --host 127.0.0.1 --port 8890
```

打开 `http://127.0.0.1:8890/#overview`，保持“自动刷新”开启即可观察动态帧。关闭自动刷新后，页面会保留当前帧，点击“刷新观测”可重新拉取完整快照。

## 这条案例还没有覆盖

真实麦克风、摄像头、NMEA 串口、雷达网口、跨传感器时间对齐、WebSocket 推送和持久化事件总线仍未接入。接入真机时，应把 `sensors/` 的仿真源替换为设备采集器，同时保留 `synthetic` 标记和来源字段。
