## 实现

- 重建 `web/index.html`，新增 `web/static/app.css` 与 `app.js`：浅灰画布、白色分组面板、单一蓝色操作色、六个导航视图、桌面侧栏和手机折叠导航。
- 值班总览保留六类观测；360° PPI 支持目标选择和 4/8/12 km 量程，超量程提示不伪造目标位置。频谱与仪表来自实际本地接口。
- 告警支持全部/异常筛选；手册检索展示章节、来源及安全格式化原文，表格可横向滚动并保留原始摘录；报告可导出 Markdown；轨迹可展开输入和输出。
- 项目介绍独立成页，说明工作流程、能力、本地与在线边界、官方 Skill 集成边界和合成素材限制。
- 六接口并发刷新，30 秒自动刷新可关闭；分析互斥，后台/阅读页面暂停自动刷新。接口错误显示重试及过期状态。
- Web 适配层固定 UTF-8、限制子进程时长、传递失败 HTTP 状态，纠正泵样本设备标签，历史轨迹按更新时间选择。增加只读手册检索与静态资源挂载。

## 验证

- `node --check web/static/app.js` 通过。
- `python -X utf8 -m unittest web.test_server -v`：6/6，通过静态资源、输入长度、中文告警、失败输出、超时、样本来源和检索参数检查。
- Edge headless / DevTools：1440×1050 桌面与 390×844 移动视口；两轮截图检查及修复确认。页面均无横向溢出、无 JS 异常。
- 实际接口六项成功；目标选择、量程排除、告警筛选、报告导出按钮、手册 3 条命中及无命中状态通过。导出验证了客户端文件名/触发路径，未执行系统级下载文件对账。
- 模拟声学请求失败，界面显示“上次数据已过期”与重试；恢复后清除错误。恶意标签文本经转义，不生成 HTML 元素。
- 复查移动菜单：收起时 inert=true，键盘选择导航并关闭后焦点返回菜单按钮。手册表格 4 列可读，窄屏局部滚动。
- impeccable 独立收尾审查初次为 fix（手册表格阅读、移动导航焦点两项）；修复后的 Verdict Pass 两项均为 resolved，结论 ship 仅覆盖这两项修复，不外推为全工程验收。

证据在忽略目录 `runs/ui-review/`：`checks.json`、`desktop.png`、`mobile.png`、`manual.png`、`mobile-manual.png`、`about.png`、`mobile-about.png`、`reports.png`、`mobile-error.png`、`preview.png`。`check.cjs` 为本轮本地 DevTools 检查脚本，依赖已运行的 Edge 调试端口 9333 和本地服务 8890，不属于产品运行依赖。

## 范围与后续

本轮不宣称 R09 全部完成：统一运行 ID、两个可执行场景切换、连续遥测、真实设备接入仍未实现。后端建模、通用 Harness、跨源证据正确性与 GB10 真机验收继续按接手计划推进。本页面也不启动训练、部署、在线语音或大脑调用。

旧报告生成器可能遗漏会遇结论；前端展示其真实输出，不补写结论。引用存在性校验在界面标为“引用已校验”，导出原文前附范围说明。

技能 context/concept-seed 启动器缺少本地引擎且无法创建缓存目录，已按技能降级条款说明。代码优先已记录在 `.impeccable/config.json`；未生成或声称批准过效果图，也没有伪造随机方向编号。设计事实与 token 记录在 PRODUCT.md、DESIGN.md 与 `.impeccable/design.json`。
