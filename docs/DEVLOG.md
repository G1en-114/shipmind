## Day 0 · 2026-09-20 · 选题

今天参加了 DGX Spark 黑客松的线上训练营，三堂课下来最大的收获不是某个 Skill 怎么用，而是想清楚了一件事：**Skill 才是 Agent 时代真正沉淀下来的资产**——prompt 是一次性的代码，Skill 是可复用、可评测、可分发的专家经验。

我们两个人，一个做二进制安全和 AI 安全，一个做机器学习。做安全方向我们商量后放弃了：那边生态已经很成熟，我们做不出增量。最后选了船舶——一个"云端 AI 物理不可行"的行业。

选船舶的理由很直接：国内船舶通信主流是 VSAT，带宽小、按流量计费，机舱的音视频持续上云做推理，费用和带宽都撑不住；机舱告警要秒级响应，卫星链路会抖会断；航线、AIS、机舱数据是船东的核心商业数据，上云出境有合规顾虑。所以"本地部署"在这里不是差异化话术，是唯一可行解。一台 DGX Spark 四万块，对一艘几千万的船，占比相当于船上的火警报警器。

产品形态定为「智舷」：能看（机舱视觉）、能听（声学异响）、能查（手册与规则 RAG）、能说（应急语音）、能记（自动日志与报告）的离线多智能体副驾。

**今天最有价值的发现**：查政策时挖到一条法条，把整个项目的必要性从"省钱省带宽"提升到了"合规硬约束"。《海上交通安全法》第二十四条要求船舶在我国管辖海域通信必须通过依法设置的境内海岸电台或卫星关口站转接——机舱音视频、AIS、航线数据在船内闭环处理，就是合规风险最低的架构，而不是"因为贵所以不上云"。另外确认了《智能船舶发展行动计划（2019—2021年）》是工信部、交通运输部、国防科工局三部委联合印发，中国船级社《智能船舶规范》2026 版今年 6 月 1 日刚生效，政策顺风是实的。

明天的第一个目标：让主 Agent 在 DGX Spark 上跑通第一个 Skill。

## Day 2 · 2026-09-21 · 大脑上线 + 真实数据第一枪

**编排大脑接电。** StepFun key 到位后探了一把模型阵容，比预期好：step-3.7-flash（262K 上下文 + 视觉）与我们文档声明完全一致，直接当大脑；step-5-preview（1M）作升级选项；step-asr/tts 全家桶让 D6 的语音链路不用另找方案。自检三连全过，包括负例——问"今天晚饭吃什么"，大脑正确返回 NONE 没有硬凑。中途踩了思考型模型的坑：content 和 reasoning 分字段，思考吃满 max_tokens 会让 content 空转，做了字段退化处理。

**本地推理端点踩了两个坑。** 先是发现节点上组委会预置了 vLLM 0.25 镜像（+torch 2.11 + CUDA 13.0，与驱动完美匹配），省了 NGC key 那条路；但 Qwen3.6-35B 的架构 `Qwen3_5MoeForConditionalGeneration` 太新，vLLM 0.25 不认识，transformers 后端也拒绝兼容——35B 在这个镜像上跑不了。改走 Qwen3-4B-FP8 先把端点跑通，30B 继续下。这不伤主叙事：编排大脑本来就是三值换端点，"StepFun API ↔ 本地 Qwen ↔ NIM 切换 + 回归评测"反而是平台适配的实证素材。

**声学 ML 轨拿到真实数据第一枪，结果是个有意思的发现。** 按 DCASE2020 官方配方（640 维 log-mel → 瓶颈 8 维 AE）重实现后，先在合成数据上冒烟（AUC 1.0）；上真实 MIMII pump 数据后，带符号重构误差 AUC 只有 0.26——比随机还差。诊断发现不是 bug：**这个子集的异常是"信号变更弱"**（异常段特征能量 8.5 vs 正常 10.4），AE 把异常重构得更好，误差自然更低，符号反了。换成方向无关的偏离度分数（|误差−训练集误差均值|），AUC 回到 **0.797**。

这个发现比一个好看的数字更有价值：它说明"异常=重构误差更高"这个 DCASE 默认假设在真实数据上不总成立，而我们的启发式轨（z-score 天然方向无关）与 ML 轨正好互为印证。代码里两种口径同时报告，不藏结果。

**顺带修了自己两个真 bug**：训练循环每 epoch 只做一步梯度（120 epoch 实际只更新 120 次，等于没训）；log-mel 未标准化导致 loss 直接 NaN。

**数据侧**：DCASE 2020 三机种（pump/valve/fan）本地下载完成，DeepShip 四类 + SeaShipsSeg 1200 张标注图已就位并传节点。两个数据集曾被我误判为"免申请"——UFPR-ADMR-v1 要机构签协议、Mileeena 合成表盘是 HF 门控（401）——所以表盘数据改为自产合成（PIL 渲染，读数+bbox 精确标签，零许可风险），与雷达 PPI 合成器同一套方法论。
