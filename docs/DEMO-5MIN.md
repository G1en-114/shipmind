# ShipMind 五分钟演示脚本

演示在 DGX Spark 的 `webui` 会话中运行，浏览器通过指南中的 SSH 转发访问 `http://localhost:8888/#overview`。当前本地开发端口也可用同样的页面验证交互。

| 时间 | 页面 | 动作 | 观众看到的计算 |
|---|---|---|---|
| 0:00–0:45 | 值班总览 | 等待首轮研判，在操作台询问“目前怎么样？” | Spark 上的 Qwen 汇总四路证据、回答问题，并把双方消息写入滚动日志 |
| 0:45–1:30 | 机舱监测 | 展示告警筛选，等待一帧更新 | 声学 Skill 输出异常样本与正常对照；频谱每 3 秒更新 |
| 1:30–2:15 | 航行态势 | 切换目标与量程 | PPI 目标、航线走廊、声纹分类在 Spark 上计算 |
| 2:15–3:00 | 日志与证据 | 展开执行轨迹，导出报告 | Harness 轨迹、报告组合和证据引用校验 |
| 3:00–3:45 | 手册检索 | 搜索“轴承磨损”和“第15条 交叉相遇” | 本地手册检索返回原文、来源和表格摘录 |
| 3:45–4:30 | 关于 ShipMind | 说明本地优先和合成数据边界 | 交代离线部署、人工复核和当前原型边界 |
| 4:30–5:00 | 回到总览 | 点击刷新观测并切换目标、量程 | 实时纸带、固定表盘指针、雷达目标和航线偏差持续更新 |

## 运行前检查

在 Spark 上按 `docs/NODE-GUIDE.md` 完成 `node_deploy.py`、夹具生成和 `webui` 重启；确认 `webui` 只监听 `127.0.0.1:8888`。演示中的 `synthetic` 字段必须保持可见，不能把合成源描述成真实遥测。

五分钟案例当前是真实 Skill 计算加本地合成传感器流。接入真实麦克风、摄像头、NMEA 或雷达网口后，只替换传感器采集层，页面和证据结构保持不变。

“Spark AI 值班官”不是预写文案：`/api/briefing` 每次从当前四路观测构造事实集，调用 Spark 上现有的 `Qwen3-4B-FP8` 生成结构化研判。页面明确标注“合成观测”，建议必须包含人工复核，不声称已控制船舶设备。

值班操作台写入 `runs/ai-duty/duty.jsonl`。默认单文件达到 2 MiB 后轮转，并保留 3 个归档；页面右上角可改为 1、2、5、10 或 20 MB。环境变量 `SHIPMIND_AI_LOG_MAX_BYTES` 可设置启动默认值，页面设置会持久化到 `runs/ai-duty/config.json`。
