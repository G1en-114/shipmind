## 1. 项目定稿

**名称**：智舷 ShipMind（暂定，9/23 前定名，此后 README / 视频 / 征文 / 仓库全部统一）
**定位**：DGX Spark 上的**船端值守多智能体副驾**——机舱线（听异响、看仪表、查手册、说处置、记日志）+ 态势线（雷达解读、声呐声纹、航线偏离），完全离线运行。

**一句话**：把一台 DGX Spark 搬上船，让值班的船员拥有一套不需要网络、不需要带宽、不需要把数据传出船外的第二班机组：一双耳朵、一双眼、一部雷达、一本手册。

## 2. 范围（四档，严格执行）

### MVP（机舱主线，必须完成，D6 冻结）

1. **听**：音频输入 → 机舱声学异常检测 → 四级分级告警，每条告警附触发特征与数值
2. **看**：同段视频抽帧 → 仪表读数与设备状态识别，与声学证据交叉确认
3. **查**：告警现象 → 检索设备手册 → 输出**带原文引用的**可能成因
4. **说**：告警与处置步骤本地 TTS 语音播报
5. **记**：事件流 → 自动生成轮机日志 + 带框图巡检报告
6. **编排**：Step 3.7 Flash（NIM 本地）主 Agent 路由
7. **Harness**：自研 Skill 运行时 + 执行轨迹录制与回放
8. **值班台 Web 界面**：告警流、频谱波形、带框截图、日志报告、轨迹回放、**航线走廊与雷达态势图**（后两项为态势层预留位）

### 冲刺层（原 Stretch 重定义，D7–D8 态势扩展 sprint，逐个独立落地、独立可砍）

| 优先级 | Skill | 技术路线 | 降级阶梯 |
|---|---|---|---|
| S1 | `route-deviation-watch` 航线偏离 | 模拟 NMEA 0183 流（RMC/GGA）→ waypoint 走廊 → XTE 越限分级 + CPA/TCPA 确定性计算。零 ML，半天级 | 无需降级，纯代码 |
| S2 | `radar-ppi-interpreter` 雷达解读 | **合成 PPI 帧生成器**（本船居中、距标环、目标回波、海杂波）→ 极坐标经典 CV（CFAR 式检测 + 聚类）→ 目标方位/距离/相对航向 → CPA/TCPA 碰撞趋势 | 检测降为阈值法；再降为只渲染态势图不做检测 |
| S3 | `sonar-acoustic-fingerprint` 声呐声纹 | 被动声纹：复用音频管线，LOFAR 窄带谱线（螺旋桨叶频谐波）+ DEMON 包谱（轴频）→ 轻量分类器（ShipsEar 数据集训练）→ 船类 + 置信度 + 证据谱线 | 分类器退化为谱线规则匹配；特征展示兜底 |

**措辞红线**：声呐能力一律表述为"被动声纹监测、民用海事感知"（港口/渔业/海事监测场景），不使用任何军用声呐对抗框架。

### Stretch 二档（仅在冲刺层全部落地且 D8 仍富余时）

- 应急 checklist 语音引导（`emergency-checklist-voice`）

### 明确不做

- 真实雷达 / AIS / 传感器硬件接入（全部用模拟源，见 §5）
- 任何云端组件进入**运行路径**（云服务器仅限开发中转，见 §3）
- 上船实测（README 如实说明局限）
- 网络安全方向功能（团队既定决策）

| 项 | 方案 |

| 手册语料 | **自拟合成手册**（结构仿真实手册、内容自控、无版权风险），README 标注"演示用合成手册" |

## 6. 自研 Harness（A 的主场，全场差异化最重）

| 组件 | 职责 |
|---|---|
| Skill 运行时 | 加载、渐进式披露（100 token 索引 → 5K 正文 → 按需 scripts）、版本管理 |
| 路由器 | 主 Agent 输出 → Skill 选择，含负向路由（不命中必须不触发） |
| 输出契约校验 | 校验结构化输出，缺字段即失败重试，残缺结果不进下游 |
| 证据审核 Agent | 独立复核结论↔证据（特征数值/视觉框/手册引用/谱线/雷达检测参数），无证据驳回 |
| 执行轨迹录制回放 | 记录输入、工具调用链、输出、耗时；回放与 diff——像调试二进制程序一样调试 Agent |
| 本地算力预算 | 模型调度与降级（如声纹分类器与机舱 AE 分时复用），防一次告警打满显存与延迟 |

## 7. 评测方案

- **Skill 级**：每 Skill 一套 `evals/cases/<skill>.jsonl`，必含正向、负向、边界三类；带/不带 Skill 各跑一遍，差值即贡献，汇总 `evals/BENCHMARK.md`（对齐 NVIDIA Verified Skills Tier3）。
- **模型级**：声学双轨对照；声纹分类器在 ShipsEar 留出集上的混淆矩阵；VLM 微调前后对照。
- **确定性模块**：航线/CPA 用构造用例做精确断言（给定输入必须得给定输出，零容差）——"确定性模块零容差、ML 模块给置信度"本身是工程成熟度的展示。
- **回归评测**：Step 3.7 Flash 切换（API ↔ NIM 本地）跑同一评测集，证明行为等价。
- 统一由 `run_evals.py` 执行出报告（D3 交付）。

## 10. 演示脚本（约 6 分钟）

1. **0:00–0:30 开场**：船上无可靠网络；《海上交通安全法》§24——数据不出船是合规要求。DGX Spark 本地运行。
2. **0:30–2:00 听**：机舱音频 → 3 号泵异响 alarm 级 + 特征数值 → 语音播报处置 → 手册 4.2.3 原文引用。
3. **2:00–2:40 看**：抽帧读表 → 与声学证据交叉确认。
4. **2:40–4:10 态势**（新）：值班台雷达态势图 → 两个目标回波被检出（方位/距离/CPA/TCPA）→ 声纹判定其一"疑似拖网渔船（置信度 + 谱线证据）"→ 航线走廊显示本船正常、目标逼近 → COLREGs 会遇咨询 → **verifier 逐条核对证据** → 语音播报 + 态势报告写入航海日志。
5. **4:10–4:50 记**：一键生成日志 + 带框图巡检报告。
6. **4:50–5:30 工程亮点**：轨迹回放；BENCHMARK.md 的带/不带 Skill 差值、声学双轨对照、声纹混淆矩阵。
7. **5:30–6:00 压测收尾**：飞行模式重跑，结果一致。

**砍法**：若冲刺层只活下 S1，第 4 段缩为"航线走廊 + 越限告警"30 秒，其余顺延，总长回落 5 分钟。
